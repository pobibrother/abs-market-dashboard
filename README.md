# 유동화시장 대시보드

2026년 11월 9일 기준 표본 10건으로 실행하는 로컬 시제품입니다. Windows와 Node.js 24 이상을 사용합니다. 별도 패키지 설치는 필요하지 않습니다.

1. 파일 탐색기에서 이 폴더를 열고 start.cmd를 실행합니다. 터미널에서는 이 폴더로 이동한 후 node server.mjs --open 을 실행합니다.
2. 브라우저의 운영자 관리에서 공용 비밀번호를 설정합니다. 서버 창은 사용하는 동안 켜 둡니다. start.cmd를 다시 실행하면 운영자 화면을 다시 엽니다.
3. 같은 PC의 시크릿 창에서 http://127.0.0.1:48731/ 로 접속해 방문자 입장을 시험합니다.

index.html은 화면, server.mjs는 서버와 비밀번호·통계 처리, data.mjs는 표본 데이터, xlsx.mjs는 엑셀 생성 코드입니다. 비밀번호 해시와 통계는 실행 시 생성되는 dashboard.sqlite에 저장되며 Git 추적에서 제외합니다. 공개 저장소에 올려도 서버는 본인 PC에서만 실행됩니다.
